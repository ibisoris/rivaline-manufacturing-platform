# Implementation roadmap

1. Phase 1: verified schema, configuration, master seed, health API and engineering contracts.
2. Phase 2: deterministic legacy exports, explicit mappings, audited ETL, row quarantine,
   idempotent replay, reconciliation/traceability and non-destructive Alembic baseline.
3. Phase 3: read-only operational APIs, bulk traceability, PostgreSQL reporting views and KPIs.
4. Phase 4: pooled inventory intelligence, BOM requirements, reorder proposals and what-if.
5. Phase 5: demand forecasting, chronological evaluation and immutable forecast evidence.
6. Phase 6 requires explicit approval before production planning/scheduling work.

No scheduling, Power BI dashboard, frontend or cloud deployment
has been added. Do not begin Phase 6 without explicit approval.
