# Requirements

- Phase 1: 23 relational entities, synthetic master data, environment-based configuration,
  local PostgreSQL configuration, health API, fast tests and documented contracts.
- Phase 2: implemented legacy ingestion with provenance and quarantine, reconciliation,
  idempotent replay and batch/supplier traceability.
- Future: explainable planning, read APIs and Power BI reporting.
- Quality: reproducibility, portable paths, decimal quantities, explicit units, no secrets,
  no proprietary data, and truthful verification claims.

Acceptance evidence is recorded in `16-phase-1-validation.md`. Future requirements should
link a synthetic business scenario to an automated check and demo step.
